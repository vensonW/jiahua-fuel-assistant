# 原表仅加油标记与独立日志及图标调整

## 摘要

用户在实看新版后明确调整输出和视觉：前两页不再追加任何辅助字段，只在加油明细原行标色；发票页不标色；详细核对数据单独写一个log。EXE文件图标恢复原红底GAWA，窗口星标透明，删除界面内部重复标题。

## 最终决定

- 保留既定金额严格零差额、升数一致、开始到结束0—30分钟、备注优先、时序一对一、多站确认及时间段输入规则。
- 结果工作簿保留所有原始工作表、字段、完整号码、原值、列宽、行高和批注，不增加核对列、结束时间列、匹配明细列或批注。
- 仅加油明细中的金额/升数不符、时间异常、无对应、待确认原始行填浅红FFC7CE，筛选范围仅原有列。发票页原有格式、筛选、冻结、缩放和可见性保持。
- 每次输出配套一个同目录、同stem的UTF-8 `.log`，保存时间来源、三种时间、双方金额/数量、差异、对应位置、依据和成功匹配明细。程序保留完整预览，提供打开日志按钮。
- xlsx和log均重名避让，不覆盖原件；两份生成成功后才报告完成，失败清理当前未交付产物。
- EXE文件资源复用原账单工具实际使用的`gawa_legacy.ico`红底黄星白色GAWA；GUI窗口星标去掉深色底框，界面只保留原生窗口标题。

## 改动点与原因

| 阶段 | 模块 | 改动 | 原因 |
|---|---|---|---|
| 已实施 | reconciliation.py | 原表标记与外部日志成对保存 | 避免原表新增大量辅助信息 |
| 已实施 | app.py | 单标题、透明图标、日志入口、说明 | 按用户实看反馈调整 |
| 已实施 | spec / assets / QA | 独立EXE红底图标、窗口透明星标 | 文件和运行窗口采用用户分别指定的图标 |
| 已实施 | tests / README / 方案 | 新导出契约和文档 | 防止未来重新插入辅助列或给发票标红 |

## 必须保持的约束

发票不重复使用，全部记录仍有核对结果，所有详细结果可在预览和log追溯。Excel原值及字段不修改，不覆盖输入文件。发票页不新增标色；已有用户格式保留。EXE文件红底不意味着GUI窗口重新出现深色方框。
