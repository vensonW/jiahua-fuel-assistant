# 加华加油与发票核对助手

界面采用浅蓝顶部、白色内容卡片和蓝色按钮。窗口、详情和任务栏使用深蓝底加华星标；EXE 文件图标恢复为原来的红底 GAWA 英文字样。

将加油明细与发票逐笔核对，直接在原工作簿前两页右侧追加结果，并将需要核查的记录整行标为浅红底。结果另存，原文件保留。

GitHub 仓库包含源码、测试、品牌资源和构建脚本。原始业务工作簿、结果文件和 EXE 保留在本地，不随代码上传；从仓库获取代码后，请自行提供输入工作簿，按下方说明运行源码或打包 EXE。

## 使用 Windows 工具

1. 双击当前目录的 `加华加油与发票核对助手.exe`，运行 EXE 无需安装 Python。`dist` 内保留构建副本。
2. 点击“数据工作簿”旁的“浏览…”，选择 `.xlsx` 文件。工作簿前两页应分别为加油明细、发票。
3. 设置核对开始、结束时间。两端默认均为 `2026-10-11`，支持 `YYYY-MM-DD`、`YYYY-MM-DD HH:MM` 或 `YYYY-MM-DD HH:MM:SS`。只填日期时，开始按当天 `00:00:00`、结束按当天最后一刻处理，包含两端边界。两项都留空表示核对全部；只留空一项、格式无效或开始晚于结束会提示更正。
4. 确认输出目录。默认保存到工具所在目录的 `outputs` 文件夹，可通过“浏览…”另选位置。
5. 点击“开始核对”，完成后查看两侧记录预览及“匹配明细”。“仅显示红底”可与“核对状态”组合筛选；双击预览行查看完整内容。
6. 点击“打开结果工作簿”，在 Excel 中通过“核对状态”表头筛选，或通过表头的“按颜色筛选”选择浅红色单元格填充。

预览筛选不会减少导出记录。结果文件重名时自动追加序号，不覆盖已有结果。程序窗口、任务栏及 EXE 使用加华品牌图标。

## 核对规则

- **应开票金额＝交易金额－优惠金额**，与发票“合计金额（含税）”比较。使用原始数值严格计算，不先四舍五入；任何非零差额，包括 `0.01` 元，都判为“金额不符”并整行标浅红底。优惠金额真正为空时按 0 计算并注明；无效内容或无法取得数值的公式标为待确认。
- 加油升数与发票数量必须完全相同，任何升数差额都不通过。
- 加油表“交易时间”为**加油开始时间**，发票备注“交易时间”为**加油结束时间**，发票“开票时间”单独保留。正常范围为 **结束时间－开始时间在 0—30 分钟内**，包含恰好 30 分钟；结束早于开始时保留负差并标为待确认。
- 备注缺少结束时间时，允许使用开票时间辅助核对，并注明时间来源；“加油结束时间”仍留空。备注有时间但格式无效时标为待确认，不能把它当作缺失后直接回退。
- 发票页保留最右侧的“加油完成时间”兼容列，其含义与“加油结束时间”相同，仅保存备注交易时间为可排序的 Excel 日期时间，缺失时留空。
- 优先根据备注油枪号及结束时间，结合加油表枪号、开始时间、油品和升数寻找对应记录；多油站数据须确认油站相符，不跨站配对。
- 同枪号、同油品、同升数的重复候选按双方时间先后一一配对，并注明“按时间顺序推定”；不能为了金额相等调换顺序。每笔加油记录、每笔发票记录最多使用一次。
- 其他信息能支持对应、但金额或其他规则不符时，可保留疑似对应位置及差额供核查；**疑似对应不计为“已匹配”**。
- 无法可靠判断、必需字段异常、同一发票多行或重复票号等情况标为“待确认”。所选时间段之外的记录保留并标为“待确认”，注明未参与本次核对。
- 同一记录存在多项问题时，全部写入配对依据；只要金额存在差额，主状态显示“金额不符”。

| 核对状态 | 含义 |
| --- | --- |
| 已匹配 | 金额、升数完全相等，结束减开始为 0—30 分钟，且配对依据成立 |
| 金额不符 | 存在对应或疑似对应，但实际发票金额与应开票金额存在差额 |
| 升数不符 | 存在疑似对应，但升数不同 |
| 时间超限 | 存在疑似对应，但结束减开始超过 30 分钟 |
| 无对应记录 | 未找到可靠对应记录 |
| 待确认 | 时间倒置、证据不足、字段异常、同票多行、重复票号，或时间段外未参与核对等情况 |

除“已匹配”外均整行标浅红底；时间段外记录按结果中的未参与说明核查。

## 结果工作簿

前两页原表右侧增加对应记录位置、对应发票号码、加油开始时间、加油结束时间、开票时间、时间来源、应开票金额、实际发票金额、金额差、升数差、时间差、核对状态、配对依据及“匹配明细”，不新增异常切页。原始字段、其他工作表、合计行和完整卡号、发票号码保留。

只有“已匹配”的记录填写“匹配明细”，两侧内容一致；异常记录该列留空，疑似对应仍在其他核对字段展示。明细在一个单元格内按项目换行，包含枪号、卡号、油品、完整发票号码、三个时间、加油与发票升数、交易金额、优惠金额、应开票金额、实际发票金额，以及双方工作表名称与原始行号。列宽与行高随内容调整，卡号和发票号码保留为完整文本。

- 金额差＝实际发票金额－应开票金额。
- 升数差＝发票升数－加油升数。
- 时间差＝加油结束时间－开始时间，以有符号分钟数展示；备注缺失时按注明的开票辅助时间计算。
- 两侧均启用表头筛选，可按状态或浅红底筛选。
- “对应”按一对加油与发票计数；红底分别统计加油侧和发票侧，两侧行数不能相加当作业务笔数。

## 2026 年 10 月 11 日样例

`中南加华加油和开票数据核对.xlsx` 中实际加油与发票各 97 笔，形成 97 对对应关系，其中 **15 对已匹配、82 对金额不符**，加油侧与发票侧各 82 行浅红底。

交易金额合计及实际发票金额合计均为 **30,181.06 元**，优惠金额合计 **1,622.02 元**，按扣优惠规则计算的应开票金额合计为 **28,559.04 元**。金额不符记录的差额等于对应优惠金额。

加油明细第 44 行原始交易金额为 `9.80`、优惠金额为 `300.00`，应开票金额计算为 `-290.20`，对应发票金额为 `9.80`。工具保留原值计算并标红，供人工核查来源数据。

核对 2026 年 10 月 1—7 日需要导入该期间实际数据，再将开始日期设为 `2026-10-01`、结束日期设为 `2026-10-07`；现有 10 月 11 日样例不能替代该期间数据。

## 源码运行与维护

使用带 Tkinter 的 Python 环境，在项目目录安装依赖后启动：

```powershell
python -m pip install -r requirements.txt
python launch.py
```

命令行也可执行核对：

```powershell
python launch.py --input "中南加华加油和开票数据核对.xlsx" --output-dir "outputs" --start 2026-10-11 --end 2026-10-11
```

精确到时分秒或核对全部记录：

```powershell
python launch.py --input "数据.xlsx" --start "2026-10-01 08:00" --end "2026-10-07 23:59:59"
python launch.py --input "数据.xlsx" --start= --end=
```

| 参数 | 用途 |
| --- | --- |
| `--input` | 输入 `.xlsx` 文件路径；无参数启动桌面界面 |
| `--output-dir` | 输出目录；默认程序所在目录的 `outputs` |
| `--start` / `--end` | 开始及结束时间，格式与界面相同；不指定时默认均为 `2026-10-11`，两项空值表示全部；只空一项无效 |
| `--date` | 兼容旧版单日参数，`YYYY-MM-DD`；`--date=` 表示全部；不能与 `--start` / `--end` 混用 |
| `--red-only` | 结果工作簿打开时默认筛选红底记录，完整数据仍保留 |
| `--summary-json` | 将本次核对摘要另存为 UTF-8 JSON |

运行回归测试：

```powershell
python -m unittest discover -s tests -v
```

在 Windows 上打包 EXE：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

打包产物为 `dist/加华加油与发票核对助手.exe`。界面位于 `app.py`，命令行入口位于 `launch.py`，工作簿解析、核对与结果导出位于 `reconciliation.py`。
